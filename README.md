## 🌟 Key Features

- **Native First Integration**: Leverages the official Omarchy CLI pipeline (`omarchy theme bg set`) under the hood to preserve smooth wallpaper transitions without breaking system symlinks.
- **Dual-Library Architecture + Existing Wallpapers Auto-Discovery**:
  - **Current Theme Library**: Tracks Omarchy's active theme (e.g. `vantablack`, `catppuccin`), indexing both built-in and user-installed theme backgrounds.
  - **Global Wallpaper Library**: Cross-theme collection that persists across theme switches.
  - **Zero-Migration Pictures Discovery**: Automatically scans and indexes wallpapers in `~/Pictures/wallpapers/` without needing to copy them.
- **Top-Bar Blind Switching Gestures**:
  - 🖱️ **Scroll Wheel Up / Down**: Instant 250ms debounced switching to previous / next wallpaper in the active scope.
  - 🎲 **Middle Click**: Pick and apply a random wallpaper within the current scope.
  - 🖼️ **Left Click**: Open / close the 3-column thumbnail gallery card panel.
  - ⚙️ **Right Click**: Open the quick context menu (Clipboard import, Add local image, Open folder, Refresh).
- **Fast Import Engine**:
  - **Wayland Clipboard Import**: Copy an image from a browser or screenshot tool, and set it as wallpaper with a single click.
  - **Zenity File Picker**: Convenient GUI file chooser to import local pictures.
  - **Security & Integrity Checks**: SHA-256 deduplication, strictly validates static PNG, JPEG, and WebP images, blocking corrupted files and oversized images (>25MB or >50MP).
- **Safe by Default**:
  - Zero background daemon — calls are executed on demand.
  - File deletion uses system trash (`gio trash`); theme wallpapers and the currently active wallpaper are write-protected against accidental deletion.

## 🕹️ Interaction Guide

| Action | Target | Behavior |
| :--- | :--- | :--- |
| **Scroll Down** | Bar icon | Switch to **Next** wallpaper (debounced 250ms) |
| **Scroll Up** | Bar icon | Switch to **Previous** wallpaper (debounced 250ms) |
| **Middle Click** | Bar icon | Pick and apply a **random** wallpaper |
| **Left Click** | Bar icon | Toggle wallpaper gallery popup panel |
| **Right Click** | Bar icon | Open context menu (import, folder, refresh) |
| **Hover** | Bar icon | Tooltip showing current wallpaper, active scope, and total count |
| **Card Click** | Gallery card | Apply selected wallpaper immediately (with checkmark badge) |
| **Heart Icon** | Card top-right | Favorite / unfavorite wallpaper (adds to Favorites scope) |
| **Folder Icon** | Card top-right | Reveal file in default file manager (Nautilus / xdg-open) |
| **Trash Icon** | Card top-right | Move wallpaper to system trash (active wallpaper is protected) |
| **Esc / Click Outside** | Any | Close gallery panel |

## 📂 Storage & Data Paths (XDG Compliant)

| Category | Path | Description |
| :--- | :--- | :--- |
| **Global Wallpapers** | `~/.local/share/omarchy-wallpaper-hub/wallpapers/` | Imported static wallpapers managed by the plugin |
| **User Pictures** | `~/Pictures/wallpapers/` | Existing user wallpapers on disk (auto-indexed) |
| **Metadata & Favorites** | `~/.local/share/omarchy-wallpaper-hub/metadata.json` | Favorite flags, import timestamps, origin metadata |
| **Thumbnail Cache** | `~/.cache/omarchy-wallpaper-hub/thumbnails/` | Fast 256px previews generated by `vipsthumbnail` |
| **Native Theme Backgrounds** | `~/.local/state/omarchy/current/theme/backgrounds/` | Read-only backgrounds bundled with the current Omarchy theme |
| **User Theme Backgrounds** | `~/.config/omarchy/backgrounds/<theme_name>/` | User backgrounds specifically placed for this theme |

> **Uninstall Safety**: Uninstalling the plugin will **never** delete your wallpaper images or favorites metadata.

## 💻 CLI Interface (`backend.py`)

All operations can be executed directly from terminal via `backend.py` with standard JSON outputs:

```bash
# Get current wallpaper status & library counts
python3 backend.py status

# List wallpapers by scope (current-theme / global / favorites)
python3 backend.py list --scope current-theme
python3 backend.py list --scope global
python3 backend.py list --scope favorites

# Switch wallpaper (next / previous / random)
python3 backend.py next --scope current-theme
python3 backend.py previous --scope global
python3 backend.py random --scope favorites

# Import image from Wayland clipboard and apply immediately
python3 backend.py import-clipboard --target global

# Import from local file
python3 backend.py import-file /path/to/image.png --target global

# Toggle favorite
python3 backend.py favorite "global:wp_xxx.png" --toggle

# Safe deletion (trashes via gio trash)
python3 backend.py delete "global:wp_xxx.png"
```

## ⌨️ Recommended Hyprland Keybindings

Add the following to your Hyprland configuration for keyboard-driven blind switching and clipboard wallpaper:

### `~/.config/hypr/bindings.conf`
```ini
# Super + Alt + W: Cycle next wallpaper
bind = SUPER ALT, W, exec, python3 ~/.config/omarchy/plugins/io.github.chivopic.wallpaper-hub/backend.py next

# Super + Alt + R: Randomize wallpaper
bind = SUPER ALT, R, exec, python3 ~/.config/omarchy/plugins/io.github.chivopic.wallpaper-hub/backend.py random

# Super + Alt + V: Apply clipboard image as wallpaper
bind = SUPER ALT, V, exec, python3 ~/.config/omarchy/plugins/io.github.chivopic.wallpaper-hub/backend.py import-clipboard
```

### `~/.config/hypr/bindings.lua` (Omarchy Lua Config)
```lua
-- Super + Alt + W: Cycle next wallpaper
hl.bind({"SUPER", "ALT"}, "W", "exec", "python3 ~/.config/omarchy/plugins/io.github.chivopic.wallpaper-hub/backend.py next")

-- Super + Alt + R: Randomize wallpaper
hl.bind({"SUPER", "ALT"}, "R", "exec", "python3 ~/.config/omarchy/plugins/io.github.chivopic.wallpaper-hub/backend.py random")

-- Super + Alt + V: Apply clipboard image as wallpaper
hl.bind({"SUPER", "ALT"}, "V", "exec", "python3 ~/.config/omarchy/plugins/io.github.chivopic.wallpaper-hub/backend.py import-clipboard")
```

## 🚀 Installation & Enabling

### Method 1: Using Omarchy CLI (Recommended)

```bash
omarchy plugin add https://github.com/chivopic/omarchy-wallpaper-hub.git --enable
```

### Method 2: Manual Clone

```bash
mkdir -p ~/.config/omarchy/plugins
git clone https://github.com/chivopic/omarchy-wallpaper-hub.git ~/.config/omarchy/plugins/io.github.chivopic.wallpaper-hub
omarchy plugin enable io.github.chivopic.wallpaper-hub right
```
